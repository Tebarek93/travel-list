# 🌳 Far Away - Packing List App

A simple and interactive packing list application built with React.

This app helps travelers organize everything they need before a trip. Users can add packing items, mark them as packed, delete items, and sort the list by different options. The application automatically tracks packing progress and displays useful travel statistics.

## ✨ Features

- ➕ Add new packing items
- ✅ Mark items as packed or unpacked
- ❌ Delete packing items
- 🔄 Sort items by input order, description, or packed status
- 📊 Live packing progress and statistics
- ⚛️ Built with React Hooks (`useState`)
- 📱 Clean and responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
